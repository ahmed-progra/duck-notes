Introducing Duck Notes 2.0, an offline Markdown notes app for Android.

Keeping useful notes involves more than capturing text. Research references, working drafts, and everyday observations need a structure that remains easy to navigate as the collection grows. Duck Notes brings writing and organization together without requiring an account or network connection.

The editor supports Markdown formatting, task checkboxes, Undo/Redo, literal Find/Replace, and Focus mode. Nested tags, pinned notes, and search filters help organize a collection. Wiki links and backlinks connect related ideas, while image attachments keep visual references alongside the text. Archive and Trash support reversible organization.

Version 2 adds Markdown import, export, and sharing, including ZIP packages for notes with images. Portable, passphrase-protected backups provide another recovery option: restore adds missing notes and leaves existing note IDs unchanged. Backup encryption protects the backup file; the live database is not separately encrypted.

Duck Notes supports English and Arabic, right-to-left layouts, themes, and adjustable editor typography. An optional device-credential app lock controls access to the interface.

The Android implementation uses Kotlin, Jetpack Compose, and Room. The source is available under the MIT License.
